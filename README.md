# Jozdani-Alzahra-Thesis
# Remaining Useful Life Prediction Using CNN-BiLSTM and Temporal Additive Attention

This repository contains the Python/Jupyter Notebook codes developed for my master's thesis in Mathematical Statistics at Alzahra University.

## Description

The aim of this research is to predict the Remaining Useful Life (RUL) of turbofan engines using deep learning models and to investigate the application of predictions in a dynamic maintenance strategy.

The implemented models include:

- Baseline CNN-BiLSTM model
- CNN-BiLSTM model with Temporal Additive Attention
- Dynamic maintenance strategy based on RUL predictions

## Dataset

The experiments are performed on the NASA C-MAPSS dataset (FD001 subset).

## Notebooks

The main implementation files are:

1. `01_Baseline_CNN_BiLSTM.ipynb`  
   Implementation of the baseline CNN-BiLSTM model.

2. `02_CNN_BiLSTM_Temporal_Additive_Attention.ipynb`  
   Implementation of the proposed CNN-BiLSTM model with Temporal Additive Attention.

3. `03_Dynamic_Maintenance_Strategy.ipynb`  
   Implementation of the dynamic maintenance strategy based on RUL prediction.

4. `04_Attention_Dynamic_Maintenance_Analysis.ipynb`  
   Additional analysis related to attention-based dynamic maintenance.
